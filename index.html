Security that ships turned on.

Four layers of protection are active before you send your first request - there's nothing to switch on.

HMAC-SHA256 Request Signing
Every request carries a cryptographic signature we verify before it's processed, so replayed or forged webhooks never reach your systems.
JWT Authentication
Short-lived, stateless tokens that revoke instantly. Nothing is stored server-side, so there are no stale credentials to leak.
Transaction Velocity Limits
Set velocity caps per merchant or per transaction. When something looks off, the alert reaches your channel in real time, not the next morning.
IP Whitelisting
Restrict API access to known server IP ranges. Anything outside the allowlist is stopped at the edge, before it ever reaches your application.
